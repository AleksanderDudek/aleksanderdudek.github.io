01

What happens to a video

Every stage writes down what it paid for. A closed laptop or a restarted worker costs the step it was on — never the whole run.

Stage 01

Ingest

A YouTube link or an uploaded file. Sources up to twelve and a half hours; anything past the transcriber's own ceiling is split into pieces and stitched back together in source time.

Stage 02

Transcribe

Word-level timestamps, cached to disk. A re-run never pays for the same audio twice — and a source with no speech is recognised as a fact about the file rather than retried for two days.

Stage 03

Select

A model reads the transcript and proposes segments, each scored for hook, engagement, value and shareability. How many it picks scales with the runtime instead of being a fixed number.

Stage 04

Render

Vertical 9:16, with the speaker kept in frame by face tracking — and the whole frame fitted instead when there is no face to track, because cropping on no evidence throws the shot away.

  • Word-synced captions, cut on silences
  • A hook title in the top safe area
  • Logo, intro and outro stings
  • B-roll, transitions, caption templates
Stage 05

Write the copy

Each clip gets its own title, description and hashtags from its own transcript — short-form copy for a Short, a full description for long-form, always naming the source it came from.

Stage 06

Queue & publish

Finished clips land on the target channel's posting calendar and go out at their slot — through a browser agent driving a publishing tool, or straight through the platform's own API.

03

A posting calendar, not a queue

Each channel keeps its own timetable in its own timezone, with short-form and long-form on separate rhythms.

Short-form slot Long-form slot Held — not claimable until released
Cadence

Times you set, kept exactly

Posts per day, the times themselves, a minimum gap enforced within each format class, and veto windows where nothing may go out. Daylight saving is handled by converting once, in the right direction.

Repair

A missed slot doesn't stop the queue

The oldest item is claimed first, so one slot stuck in the past blocks everything behind it. A sweep re-anchors stale slots onto the channel's own calendar — never "post it all now".

Safety

Inert until you say otherwise

A channel starts with publishing off and every item held. Nothing reaches a real account until an operator switches both on deliberately.

04

The rest of the rack

Everything the pipeline grew once it started running unattended.

Watch

Watched channels

Follow a channel and turn what it publishes into clips automatically. Filter by duration band and by title, in whole words and accent-insensitively — so "trailer" matches an official trailer and "art" does not match "Start".

Voice

Personas & narration

Commentary is written and spoken in a persona you define — a register, a language and a voice. Cloud voices, a cloned voice, or local synthesis where nothing leaves the machine.

Look

Channel designs

One palette, typeface and caption style per channel, read by both renderers — so an opening card and the captions four seconds later cannot disagree about what the channel looks like.

Lang

Languages that actually render

Fonts are checked for coverage before a render, not after. A typeface that cannot draw ą ć ę ł ń is swapped for one that can, matched by weight so a poster face is replaced by a poster face.

Data

Analytics that answer a question

Runway — how many days each channel keeps posting before it runs dry. Output by template with average virality. A source library showing which links have been cut, and into which formats.

Again

Reposting

Rank what already published by a score you weight yourself, then send the best of it round again on the same calendar.

Resume

Nothing paid for twice

Downloads, transcripts, model answers, narration and finished renders are all cached by content. A clip is named after what it is, so a re-run lands on the same file instead of a second copy beside the first.

Keep

A library of the good ones

Mark a clip worth keeping and it is copied into a folder you can actually open, named after the source and its hook rather than a hash — and the mark protects the file from the cleanup that runs once a clip has published.

API

Driveable from outside

A REST API with per-user keys, and an MCP server so an assistant can start a job, watch it, and fetch the clips when it finishes.

Askpersonal licences by request — it is not open source

It is not open source. MegaVideoPublisher is proprietary, and running it needs a licence. Personal licences are granted on request — get in touch and say what you want to use it for.

Bring your own keys. Transcription and the language model are services you configure with your own credentials. What it costs to run is between you and those providers.

Publish only what you have the right to publish. The tool does not decide that for you. Formats built on someone else's material report how much of the result is genuinely yours, and refuse to render below the floor you set.

Your accounts stay yours. Connecting a channel stores its token on your own machine and uses it for nothing but posting your clips to that channel. Revoke it at any time and it stops.
